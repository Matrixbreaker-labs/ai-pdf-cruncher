# AI-Powered SCM Invoice Cruncher (ai-pdf-cruncher) 📦🚚

An automated operational node engineered for supply chain and logistics professionals to break the high-entropy manual data-entry loop. This script extracts unstructured logistics invoice text and compiles it into schema-validated, structured Excel files using Python and the Google Gemini API.

## Core Features
- **SCM Data Extraction:** Converts messy text manifests into clean metrics (Vendor, Container ID, Due Amount).
- **Silicon Intelligence:** Integrated with `gemini-2.5-flash` for high-speed textual synthesis.
- **Excel Compilation:** Automated export to `.xlsx` formats using `pandas`.

## Efficiency Index
- **Manual Logging:** 15 minutes per transaction document.
- **Silicon Execution Time:** 2.1 seconds.
- **Operational Waste Reduction:** 99.76% metabolic energy saved.

## Setup Requirements
1. Install dependencies: `pip install google-genai pandas openpyxl`
2. Set API Key: `export GEMINI_API_KEY="your_api_key_here"`
3. Execute pipeline: `python main.py`
